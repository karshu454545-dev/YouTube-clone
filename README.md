## 📸 About the Project
This project is a static clone of the YouTube homepage. It replicates the layout and design of YouTube including the navigation bar, sidebar, and video grid — built entirely with HTML and CSS without any frameworks.

## ✨ Features
- 📌 Sticky top navigation bar with logo, search bar, and icons
- 📂 Sidebar with navigation links (Home, Explore, Subscriptions, Library, etc.)
- 🎞️ Responsive video grid with thumbnails, channel pictures, titles, and view counts
- ⏱️ Video duration overlay on thumbnails
- 🖼️ Clean layout closely matching the real YouTube homepage

## 🛠️ Technologies Used
| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout (Flexbox & Grid) |

## 📁 Project Structure
```
YouTube-clone/
├── index.html         # Main HTML file
├── style.css          # Stylesheet
├── icons/             # SVG icons (hamburger, search, etc.)
├── channel-pictures/  # Channel profile images
└── thumbnails/        # Video thumbnail images
```

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/karshu454545-dev/YouTube-clone.git
   ```
2. Open `index.html` in your browser.
